かんたん操作

和子さんの使い方

👂

みみサポート（相手の話を文字にする）

  1. 1ホーム画面の「みみサポート」をタップします。
  2. 2「はなしかけてもらう」の大きなボタンを押します。
  3. 3相手に話してもらうと、その内容が大きな文字で出てきます。
  4. 4終わったら、もう一度ボタンを押すと止まります。
📺

テレビ電話（かおを見て話す）

  1. 1ホーム画面の「テレビ電話」をタップします。
  2. 2かけたい相手の名前が並んでいるので、タップするだけで電話がかかります。
  3. 3誰かから電話がかかってきたときは、画面いっぱいに「でる」「でない」の緑と赤のボタンが出ます。緑の「でる」を押すと話せます。
  4. 4話し終わったら、赤い電話のボタンをタップします。
☀️

きょうのレッスン（毎日のお楽しみ）

  1. 1ホーム画面の「きょうのレッスン」をタップします。
  2. 2今日の日付を答えたり、思い出のお話をしたり、ことば遊びや、かんたんな問題に答えます。
  3. 3最後まで終えると、スタンプがもらえます。「あしたのお楽しみ」も出てきます。
わからなくなったら、画面の左上の「←」ボタンか、いちばん上の名前をタップすると、いつでもホーム画面に戻れます。むずかしいことはありません、気楽に押してみてください。
セットアップ

ご家族の設定ガイド

はじめての設定チェックリスト

  • 設定 →「お名前」で、あいさつに使う名前を登録した
  • 設定 →「文字の大きさ」を、見やすいサイズに合わせた
  • ブラウザのホーム画面に追加した（アイコンをタップするだけで開けるように）
  • テレビ電話の「あなたの番号」（6桁）を、他のご家族に伝えた
  • テレビ電話に、よく話す相手を登録した
  • 思い出データベースに、写真を数枚登録した

思い出データベースの登録方法

  1. 設定 →「思い出データベースを管理する」を開きます。
  2. 写真・動画・PDFのいずれか1つを選びます。
  3. 「質問」に、たとえば「これは誰でしょう？」のように入力します（🎙️ボタンで声でも入力できます）。
  4. 「答え・説明」に、あとで見返す内容を入力します（空でも構いません）。
  5. 「保存する」を押します。登録した内容は、レッスンの「思い出のお話」の時間に自動的に使われます。

バックアップの取り方

  1. 設定 →「バックアップを保存する」を押すと、記録一式が1つのファイルにまとまってダウンロードされます。
  2. このファイルは、Google DriveやOneDrive、パソコンなど、この端末以外の場所にも保管してください。
  3. 元に戻したいときは、同じ画面の「ファイルを選択」から、そのファイルを選ぶだけです。
記録はこの端末のブラウザ内にのみ保存されます。特にiPadは、しばらく開かないと自動的にデータが消えることがあるため、月に一度程度のバックアップをおすすめします。

テレビ電話の期限について（重要）

テレビ電話は無料のFirebaseという仕組みを使っています。作成時に選んだ「テストモード」は、作成から約30日で自動的に閉じてしまい、それ以降テレビ電話が使えなくなります。期限が近づく前に、以下の手順でルールを更新してください（一度行えば、以後は無期限に使えます）。

  1. Firebase Console にログインし、プロジェクト「mimi-to-kokoro」を開く。
  2. 左メニュー「構築」→「Firestore Database」→ 上部の「ルール」タブを開く。
  3. 表示されている内容を、下のコードにすべて置き換える。
  4. 「公開」ボタンを押す。
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /calls/{callId} { allow read, write: if true; match /{subcollection}/{docId} { allow read, write: if true; } } } }
